# 需求说明
## 角色与范围
- 报修人：查看设备信息、提交报修工单
- 维护人员：查看设备信息、更新工单状态

## FR‑01 查看设备信息
角色：报修人、维护人员
前置条件：无
输入：设备编号
行为与正常结果：系统根据输入的设备编号，查询并展示对应的设备信息
异常结果：输入的设备编号不存在，系统给出提示信息
验收方法：
1. 输入合法存在的设备编号，可以正常看到设备信息
2. 输入不存在的设备编号，系统给出提示，不展示设备

## FR‑02 提交报修
角色：报修人
前置条件：无
输入：选择设备、填写故障描述
正常结果：故障描述不为空，系统生成工单，工单初始状态为 PENDING
异常结果：故障描述为空或者信息不全，不生成报修工单
验收方法：
1. 选择设备+填写非空故障描述，成功创建PENDING工单
2. 故障描述为空，无法生成工单

## FR‑03 更新工单状态
角色：维护人员
前置条件：目标工单已存在
允许的转换：PENDING → PROCESSING、PROCESSING → COMPLETED
拒绝的转换：PENDING→COMPLETED、PROCESSING→PENDING、COMPLETED→任意状态等所有其余流转
正常与异常结果：合法流转时更新工单状态；非法流转直接拒绝变更
验收方法：
1. 维护人员执行允许的状态切换，工单状态更新成功
2. 执行不允许的状态跳转，系统拒绝修改，状态保持不变

## 已确认的实验规则
工单状态仅支持：PENDING、PROCESSING、COMPLETED
